# v0.2：用户《法门寺》清唱样本调试

使用用户提供的「法门寺-刘公道做事真胆大（清唱版）.mp3」，容器时长约 22.91 秒，解码音频约 22.86 秒，立体声 44.1 kHz。录音仅用于本地调试，不包含在站点资产或源码中。

## 发现与处理

旧版逐帧周期估计在强二次泛音位置容易返回两倍频率；孤立三点清理无法修正持续数帧的错误。典型情况为 5.3 秒附近，基频约 326 Hz，旧版输出约 651 Hz。

比较了 librosa 0.11 pYIN（1024／2048 样本窗）、本地候选路径试验、torchcrepe 0.0.24 的 tiny／full 模型。pYIN 显著减少短时翻倍，但在本段结尾仍有高音误判。CREPE 的结果与频谱基频走向更一致，所以本版采用 tiny 模型在浏览器运行；full 仅在本地做交叉参照。RMVPE 仅调研，本次没有运行它。

默认音域保持 75–1400 Hz，没有针对本录音把音域缩窄到预期音区。默认 16 kHz 输入，1024 样本居中窗，20 ms 步长；三角转移 Viterbi、局部加权频率细化、0.12 置信度门限。不对音高施加整句平均或全局音区限制。

## 频谱核对位置

从局部频谱的基频和整数倍泛音关系选取稀疏检查点。由于滑音、窗长和谐波展宽，Hz 是近似范围，测试允许约半音以内的常规偏差；快速转折的点允许更大一点的偏差。

| 时间 | 频谱基频近似 | 旧版输出 | 浏览器新版输出 |
| --- | --- | --- | --- |
| 0.65 s | 约 315 Hz | 649 Hz | 305 Hz |
| 1.05 s | 约 382 Hz | 758 Hz | 377 Hz |
| 4.25 s | 约 334 Hz | 678 Hz | 325 Hz |
| 5.30 s | 约 326 Hz | 651 Hz | 326 Hz |
| 12.05 s | 约 328 Hz | 659 Hz | 326 Hz |
| 17.80 s | 约 346 Hz | 345 Hz | 347 Hz |

新版保留约 805 个有声点，旧版约 770 个。新版估计范围约 208–389 Hz，旧版约 115–1063 Hz。这些是样本描述，不是完整音高准确率。

与 CREPE full 的有效输出共同覆盖的 790 帧中，约 98.1% 的差异小于 50 音分，中位差约 10.3 音分。两者属于同一模型家族，这只表示交叉一致性，不能当作人工标注准确率。完整曲线仍未有逐帧人工真值；尚不能推断其他行当、流派、音域及伴奏条件的效果。

## 播放交互验证

固定当前时间在主图中央：`view.start = currentTime - span / 2`。保留曲首／曲尾留白，不夹紧成分段翻页。每个播放帧连续滚动，当前位置标点只在有可靠音高时显示。

自动浏览器检查覆盖本录音的 0、4、7.98、8.02、22.7 秒以及 4／8／16／32 秒视野，检查播放线像素是否保持中央；检查实际播放、暂停、缩放和手机布局。另保留 MP3 解码、保调慢放、声部切换、A/B 与拖动循环、唱词和节拍校正检查。

运行真实录音回归：

```bash
node tests/famen-recording.mjs /path/to/recording.mp3
```

原文件 SHA-256 和稀疏频谱检查点在 `tests/famen-validation.json`。这份测试不会把音频发送到服务器。
