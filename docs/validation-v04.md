# v0.4：起唱、字幕、字音与同步

## 本次修改

- 浏览器分离上限由 180 秒改为 600 秒。约 23.8 秒一块，约 2 秒上下文及 93 ms 渐变，全曲共享峰值、共同增益，严格保留原始样本位置。
- 增加从首句唱起，优先采用唱词时间，否则采用分析声部的持续有声起点估计；界面标明来源。
- 曲线下显示当前唱词，增强 LRC 高亮当前字／词；普通 LRC 同步到句。支持字幕隐藏、空结束标记及逐句校时。
- 接入用户字表，普通话与戏曲参考注音分别有来源；有提示的句子标红，特殊字带点线，多读法和缺失读法均显式保留，支持本段逐字校订。
- 用同一个输出时钟绘制曲线、当前音高和字幕，自动补偿可测音频输出延迟，增加 ±1000 ms 手动微调。

## 字表来源

用户归档 workspace-01a05838-3618-7cec-a744-7247bff4f25f.zip 中「京剧音韵资料/index.html」的 DATA 字面量可安全解析为 JSON。提取 DATA.jian（1324 个尖／团字条目，其中 485 尖字）和 DATA.shang（804 个上口字），未执行 HTML/JS，未纳入完整旧唱词库、原 ZIP 或用户音频。

旧表不是音频识别结果，也不是对所有流派的规范字音结论。有些字有多个读法，有些条目读法缺失，部分拼写是戏曲拟音。参考声调类别转写带调拟音，普通话按上下文生成；校音针对本句该次出现。字音校订及时间标记尚未跨刷新保存。

## 验证与范围

- 40 项单元检查通过：原有音高、平滑、短缺口、声部分解、画面居中；新增首唱起点、600 秒边界、长段分块的工作区与拼接样本对齐、输出时间／慢放换算、字幕结束标记、字音候选／覆盖、文本安全与连续性。
- 原有浏览器操作检查通过：真实 MP3 解码、模型音高绘制、慢放保调、声部切换、循环、歌词、手机布局。
- 用户提供《法门寺》清唱的谱峰锚点、曲线覆盖、平滑、居中视野和手机检查通过。
- 用已核对 SHA-256 的真实 UVR 模型和短混合音频完成浏览器分离，验证人声分析、位置保留、声部切换、模型缓存、取消和没有音频上传。
- 新浏览器检查覆盖：有声／LRC 首句来源、起唱跳转、增强字幕、红句与 ruby 注音、多读法、逐字校音、显隐偏好、慢放微调、结束标记、手机布局。检查中的唱词是功能测试文本，非对真实清唱的转写。
- 分块算法用确定性预测器验证边界、渐变连续性和样本位置；未完整运行 10 分钟的神经网络分离。支持上限不等同于所有设备均可承受的曲长或速度承诺，输出／播放音源内存仍随总时长增长。

## 同步实测

本地 Chromium 用已知脉冲经 HTMLAudioElement → AudioWorklet → AudioContext.destination 检查。媒体时间相对 getOutputTimestamp 推算的设备输出位置领先约 38–41 ms；自动补偿后与探针的差异约一个渲染量子。该数值只说明本地浏览器链路，不能推断用户耳机、系统或真实听感延迟。

音高窗本来已按时间居中，无需额外扣半窗；对称显示平滑的颤动回归最优相关滞后为 0 帧。剩余不一致可能来自实际设备未报告的输出延迟、歌词时间本身或模型的局部识别误差。自动补偿配合手动微调用于前者；未把听感问题归因于使用者反应。

按用户要求仅上口字标红、注音；普通字与仅尖团差异的字显示普通文字，句子不整体标红。曲线字幕与唱词列表共用规则；多读法、校音、普通话切换和字／词时间跟随保持可用。40 项单元检查及字幕浏览器回归通过，包含混合句的实际字色、注音数量、校音取消提示与恢复、字幕显隐、慢放微调及手机布局。
